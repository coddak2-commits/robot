v1.1.224 - 수직 파트 시작 체류 제거 (기어가기 + 제자리 정지 둘 다)

■ 변경
수직 파트(P1/P3/P7/P9) 시작점의 체류를 없앤다.
아크를 켜고 곧바로 배치 이동으로 들어간다.

  PART_START_DWELL_MS
    이전  p1: 500, p3: 500, p7: 500, p9: 500,  p4: 1000, p10: 1000
    이후  p1: 0,   p3: 0,   p7: 0,   p9: 0,    p4: 1000, p10: 1000

수평(P4/P10)의 1000ms 제자리 정지는 그대로다.

기어가기(PART_START_CREEP)는 수직에서만 쓰이던 기능이라 체류가 0이 되면
자연히 실행되지 않는다. 체류만 되살리고 기어가기는 끈 채로 두고 싶을 때를
위해 PART_START_CREEP_ENABLED = false 플래그를 남겨뒀다.
기어가기 코드 자체는 지우지 않았다.

■ 경위
v1.1.205에서 '제자리 정지'를 '아주 느린 짧은 이동'으로 바꿨다.
정지 상태에서는 위빙 궤적이 안 나오고(2026-09-29 현장 확인),
아크 직후 10~15mm 구간이 차가워 비드가 얇게 깔리는 문제가 있었다.
v1.1.211에서 3mm -> 12mm, v1.1.213에서 5mm/0.7 비율로 조정했다.
v1.1.210에서 수평은 2026-09-30 모션 물림 사고 뒤 제자리 정지로 되돌렸다.

2026-10-06 사용자 판단으로 수직도 시작 체류를 쓰지 않기로 했다.

■ 되돌리는 법
제자리 정지만: PART_START_DWELL_MS 의 p1/p3/p7/p9 를 500으로.
기어가기까지:  위에 더해 PART_START_CREEP_ENABLED 를 true 로.
기어가기를 다시 켤 때는 welding_config 의
arc_tracking_refer_sample_start_ud 와 구간이 겹치지 않는지 확인할 것
(v1.1.213 주석 참고).

■ 확인 방법
수직 용접 시작 시 robot_core 로그에서
Weave START 다음에 vel 이 1% 미만인 MoveL 이 없어야 한다.
(10/06 로그 예: 14:39:52.571 MoveL vel=0.321813 - 이 줄이 안 나와야 한다)
Weave START 직후 바로 Batch MoveL start 가 와야 한다.

■ 적용 범위
weldingCore/weldingExecution.ts 는 펜던트와 셀 선택 화면이 함께 쓴다.
양쪽 모두 동작이 바뀐다.
