v1.1.212 - 횡단 전환 후퇴 실패 대응 (P1 와이어 간섭)

■ 문제
파트 전환에서 P1(좌측 상단, z=554) 후퇴가 도달 불가로 거부된다.

  2026-09-30 15:59:32.465  MoveL pos=[-466.203,-505.488,554.326,...] vel=30
  2026-09-30 15:59:32.476  MoveL() -> code=112 | 직선이동 실패
  2026-09-30 15:59:32.480  MoveJ 홈

물러나지 못한 자리에서 홈으로 MoveJ 하므로 와이어가 모재를 스친다.
아크 트래킹으로 스틱아웃이 20mm 안팎으로 일정해지면서 더 자주 닿는다.
P7 은 마지막 파트 종료라 뒤에 횡단 이동이 없어 증상이 없었다.

그리고 이 실패가 예외로 올라가 용접 사이클 자체가 중단됐다.
같은 로그에서 16:01 수동 와이어 작업 -> 16:03 터치센싱 재시작으로 이어진다.

■ 수정
후퇴 거리를 단계적으로 줄여 재시도한다.

  const CROSS_RETRACT_RATIOS = [1, 0.7, 0.45, 0.25];
  const CROSS_RETRACT_MIN_MM = 15;

touch_sensing_home_retract_offset=100 기준으로 100 -> 70 -> 45 -> 25mm
순으로 시도하고 처음 성공한 거리를 쓴다. 전부 실패하면 경고만 남기고
진행한다. 후퇴 실패는 사이클 중단 사유가 아니다.

로그로 확인한다.
  후퇴 100mm 실패 (status=500 code=112) - 거리를 줄여 재시도
  파트 전환(횡단): P1 후퇴 100mm -> 70mm 로 축소 적용

■ 주의
touch_sensing_home_retract_offset 값을 올리면 안 된다.
현재 100 에서 이미 P1 이 도달 불가다. 올리면 더 확실히 실패한다.

적용 범위는 횡단 전환(좌 <-> 우)뿐이다. 같은 쪽 전환 ①의
approachOffset 후퇴(현장 25mm)는 실패 이력이 없어 그대로 둔다.
