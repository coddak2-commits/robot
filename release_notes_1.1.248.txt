v1.1.248 - 수평 시작점(P4/P10) 접근 자리를 터치로 잡힌 구석 기준으로 계산

[배경]
2026-10-14 08:13 수평 시작 P4 에서 와이어가 구석에 꽂히며 휘었다.
P4 로 들어가는 코드는 226/227 과 같다. 달라진 것은 교시 위치다.
  227 시절 P4 : 옆벽에 붙여, 뒷벽에서 약 45mm 앞, 바닥 위 약 21mm (작업 484/485)
  10-14  P4 : 구석 가까이, 바닥 위 약 11mm
접근 자리가 '교시 좌표 + 접근 거리'(터치 보정 없음)이고 최종 하강이 '교시 + 터치 보정'
이라, 교시 위치에 따라 마지막 직선 이동의 방향이 바뀌었다. 10-14 에는 옆 17mm·아래 11mm 를
한 번에 꺾어 구석에 꽂혔다. 사람이 찍는 위치는 매번 다르므로 교시에 의존하지 않게 한다.

[수정]
    weldingCore/weldingExecution.ts getTouchedStartApproachOffset
      수평 시작점(P4/P10)의 접근 자리 =
        교시 + 터치 보정 + 접근 방향 거리 + 바닥 위 15mm + 반대쪽 벽에서 3mm
        P4 : 접근 +X, 옆벽(-Y)에서 +Y 3mm
        P10: 접근 -Y(종전 방향 유지, +X 는 code=185), 뒷벽(-X)에서 +X 3mm
      거기서 종전처럼 '교시 + 터치 보정'으로 직선 하강한다. 도착 위치는 종전과 같다.
      매번 구석에서 같은 거리·높이에서 같은 방향으로 비스듬히 내려가 들어간다.
      적용: 용접 시작 접근(P4 가 첫 포인트일 때)과 파트 전환 ②(P1 -> P10 횡단 진입).
      4파트 구성에서만, 터치 보정이 있을 때만. 없으면 종전 방식.
      토치 각도(rx/ry/rz)는 종전처럼 교시 값을 쓴다.
      로그: welding.start.approachTouched / welding.partTransition.approachTouched
