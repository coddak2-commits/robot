v1.1.217 - 용접 종료 후 최종 후퇴 실패 시 base +X 재시도

■ 문제
모든 용접이 끝난 뒤의 최종 후퇴가 P1(좌측 상단)에서 실패한다.

  2026-10-01 15:03:22.573  MoveL pos=[-473.516,-493.813,539.702] vel=30
  2026-10-01 15:03:22.583  MoveL() -> code=112 | 직선이동 실패
  2026-10-01 15:03:22.589  MoveJ 홈

경고만 남기고 홈으로 MoveJ 하므로, 물러나지 않은 자리에서 팔이 움직여
와이어가 모재를 스친다(현장 확인).

v1.1.212/214 에서 넣은 거리 축소 재시도는 '파트 전환' 후퇴에만 들어갔다.
이건 '전체 종료 후 최종 후퇴'라 다른 코드 경로이고 방향도 다르다.

  파트 전환 후퇴   base +X          재시도 있음 (212/214)
  최종 후퇴        토치축 -Z 100mm  재시도 없음  <- 이번 건

토치축 -Z 100mm 는 2026-09-22 에도 P1 에서 같은 112 로 거부된 방향이다.

■ 수정
토치축 -Z 가 거부되면 base +X 로 거리를 줄여가며 다시 시도한다.
v1.1.212 의 retreatBaseX 를 그대로 쓴다(100 -> 70 -> 45 -> 25mm).

토치축 -Z 가 되는 끝점(P7/P12 등)은 종전대로 그쪽을 먼저 쓴다.
실패했을 때만 대체 경로로 넘어간다.

로그로 확인한다.
  최종 후퇴(토치축 -Z 100mm) 실패 (status=500) - base +X 로 재시도
  최종 후퇴: base +X 70mm 적용

전부 실패하면 경고만 남기고 진행한다. 후퇴 실패가 중단 사유는 아니다.
