v1.1.234 - 와이어 조그 재보정 (v1.1.233 정정, 식은 쪽 · 당기기 포함)

v1.1.233 의 전제가 틀렸다. 그때 쓴 두 측정 중 '용접 전' 쪽은 식은 상태였는데
뜨거운 상태로 보고, 식은 데이터와 뜨거운 데이터를 섞어 뜨거운 프로파일을 냈다.
233 설치 후 다시 재보니 '용접 전' 값이 233 이전과 거의 같았고(233 은 식은 쪽을
건드리지 않았다), 이것이 전제가 틀렸다는 증거다. 233 의 뜨거운 값
(-84ms, 10.26mm/s)은 폐기한다.

[식은 상태 - 밀기]
    208 값(306ms, 6.56mm/s) 기준, 명령 시간 458 / 1068 / 4117ms.

      요청      1차      2차       평균
      1mm       2mm      3mm       2.5mm
      5mm       9mm      7~9mm     8.5mm
      25mm      35mm     31~34mm   33.75mm

    세 점 최소제곱 -> L(mm) = 8.46 x (t - 0.117s)
      속도 6.56 -> 8.46 mm/s,  지연 306 -> 117 ms
    검산: 25mm -> 3072ms -> 25.0 / 5mm -> 708ms -> 5.0 / 1mm -> 235ms -> 1.0

[뜨거운 상태 - 밀기]
    218 값(7ms, 7.54mm/s) 기준, 용접 직후 1회. 명령 시간 670 / 3323ms.
      요청 5mm -> 6mm,  요청 25mm -> 35mm
    두 점 -> 속도 7.54 -> 10.93 mm/s,  지연 7 -> 121 ms
    검산: 25mm -> 2409ms -> 25.0 / 5mm -> 579ms -> 5.0

    같은 측정의 1mm(140ms -> 3mm)는 21mm/s 에 해당해 물리적으로 안 맞는다.
    눈대중 오차로 보고 버렸다. 뜨거운 쪽은 측정이 1회뿐이라 신뢰도가 낮다.
    용접 직후 다시 재서 어긋나면 같은 방식으로 5mm·25mm 두 점만 다시 재면 된다.

[당기기 - 양쪽 공통]
    160 값(220ms, 23.4mm/s) 기준, 식은 상태 1회. 명령 시간 263 / 434 / 1288ms.
      요청 1mm -> 2~3mm,  5mm -> 3mm,  25mm -> 23mm
    5·25mm 두 점 -> 속도 23.4 -> 23.42 mm/s,  지연 220 -> 306 ms
    속도는 맞았고 지연만 모자랐다. 당기기는 160 이후 처음 잰 것이다.
    1mm 측정(263ms -> 2.5mm)은 새 지연보다 짧은 펄스라 0mm 여야 하므로
    역시 눈대중 오차로 본다.
    당기기는 두 상태를 나누지 않고 양쪽에 같은 값을 쓴다(종전 방식 유지).

[한계]
    1mm 는 어느 방향이든 +-1mm 가 한계다. 펄스가 수백 ms 밖에 안 되고 HTTP
    왕복 시간이 그 안에서 차지하는 비중이 크다. 송급에 엔코더가 없어 실제
    길이를 되먹임할 방법이 없으므로, 롤러 압력·라이너·스풀이 바뀌면 또 틀어진다.
