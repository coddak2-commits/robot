## 규명된 사실

- **우측 점화 지연(0.25초)은 위치 원인 아님.** 확인 터치 결과 보정 후 남은 거리 좌우 모두 2.8~3.3mm. 재현 여부는 미확인.
- **경유점 방식(167) 9/21 실용접:** 좌측 수직 곧게 나옴. 우측 P8에서 비드 꺾임(경유점에서 방향이 바뀌는 구조적 특성, 모든 경유점에서 생길 수 있음). 좌측 수평은 P5를 약 20mm 지나 `MoveL code=-4`로 정지.
- 에러 코드: `-4` = XMLRPC 명령 실행 실패(통신, 9/15 단일 MoveL에서도 발생, 원인 미규명) / `112` = 목표 자세 도달 불가 / `185` = 직선이동 실패
- 1.1.171에서 "P7에서 매번 쓰는 후퇴"라고 한 건 틀렸음. 옛 순서의 용접 종료 후퇴는 P12(바닥)에서만 쓰였음.
- 스플라인(1.1.156) 코드는 전부 연결돼 있으나 한 번도 실행 안 함. 미검증: 이동 완료 대기(마지막 점 blendR=-1), 속도 환산(0.431), 위빙 조합.

## 사용자 작업 방식

한 번에 한 주제. 수정은 승인받고 진행. 짧게, 이모지 없이, 존댓말 한국어. PowerShell 기준(`&&` 금지), `.bat`는 PowerShell에서 실행. 코드 수정 후 빌드~릴리즈 명령까지 제시. 버전은 파일에서 확인. 요청 안 한 제안·다음 단계 나열 금지. 용접 중 현장 실측 요청 금지 — 로그와 사진으로 판단.
