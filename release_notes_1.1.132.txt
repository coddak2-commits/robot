v1.1.132

- 와이어 조정 버튼(Wire In/Out) 정지 안전성 수정. 로봇 동작 로직은 변경 없음.
- 문제 1: 1회 피딩의 정지 명령이 setTimeout 콜백 안에서 try/catch 없이 호출돼, 정지 요청이 실패하면 unhandled rejection으로 조용히 끝나고 와이어가 계속 송급됐음. -> 최대 3회(150ms 간격) 재시도하고, 그래도 실패하면 "비상정지로 멈추라"는 에러 팝업을 띄움.
- 문제 2: 1회 피딩 경로에서 wireFeeding 상태를 세팅하지 않아, 정지가 실패해도 화면의 정지 버튼으로 멈출 수 없었음. -> 송급 시작 전에 상태를 올려 항상 정지 버튼이 살아있게 함.
- 문제 3: 화면 이동/언마운트 시 타이머가 사라져 정지 명령이 영영 나가지 않을 수 있었음. -> 언마운트 시 타이머 정리 + 남아있는 송급 정지.
- 문제 4: 연타하거나 반대 방향 버튼을 누르면 이전 펄스 타이머가 남아 엉켰음. -> 이전 타이머를 먼저 정리하고, 반대 방향이 돌고 있으면 확실히 세운 뒤 시작.
- 툴팁 문구 수정: Wire In/Out 버튼의 "(1mm)" -> "(소량)". 실제 1회 피딩량은 WIRE_TARGET_MM=0.2mm라 표시가 틀려 있었음.
