v1.1.232: 터치 Z 여유값 추가 · 수평 시작 체류 제거

- welding_config 에 touch_offset_depth_z 추가 (기본 0, 프런트에서 0~30 제한).
  터치 결과 dz 에 더해 토치를 그만큼 높이 세운다. touch_offset_depth 는 X/Y 에만
  붙어서 토치가 접촉 높이에 그대로 섰고, CTWD 가 터치 당시 와이어 길이와 같아져
  스틱아웃이 와이어 길이에 끌려다녔다(2026-10-08 현장: 25mm 맞춰도 용접 중 15mm).
  Z 탐색을 실제로 한 포인트에만 적용한다.
  robot-core: 구조체 + SELECT + row 파싱 + 로그 + JSON 입출력.
  프런트: WeldingConfig 타입, WeldingSequenceSettings, sequenceSettings 매핑,
  touchSensing 적용. 설정 화면은 없고 DB 에서 직접 바꾼다.
  database/migrations/013_touch_offset_depth_z.sql

- weldingExecution.ts PART_START_DWELL_MS 전부 0 (P4/P5/P10/P11 의 1000ms 제거).
  이 체류는 모서리 충전용이었는데(1.1.158/202) 1.1.228 에서 모서리를 별도 파트로
  떼면서 역할이 넘어갔다. 같은 자리에 겹치면 2초를 머물며 쌓기만 한다.
  키는 남겨둔다. (1.1.224 에서 수직 0, 여기서 수평·모서리 0)

- touchSensing.ts 에서 중복 포인트 제거. flattenExecutableParts 가 파트를 그대로
  이어붙이는데 1.1.228 이후 P3/P9 가 두 파트에 들어가 터치센싱을 두 번 돌았다.
  결과는 같고 시간·접촉 횟수만 낭비였다(와이어가 탐침이라 접촉마다 소모된다).
