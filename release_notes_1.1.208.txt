v1.1.208 - 와이어 수동 송급(밀기) 재보정

■ 문제
"와이어 조정" 버튼의 실제 송급량이 요청값보다 적었다.
현장 반복 실측: 5mm 요청 -> 약 2.5mm, 25mm 요청 -> 약 20mm.

■ 원인
모터 ON 후 와이어가 실제로 움직이기까지의 지연(deadTime)이
실제보다 훨씬 작게 잡혀 있었다(20ms). 그래서 짧은 값일수록
모자라는 비율이 커졌다.

■ 수정
robot-front/src/lib/wireFeed.ts 의 밀기 프로파일 재산출.
  속도 = (20 - 2.5)mm / (3353 - 687)ms = 6.56mm/s
  지연 = 687ms - (2.5 / 6.56) * 1000 = 306ms

  밀기: deadTimeMs 20 -> 306, speedMmPerSec 7.5 -> 6.56
  당기기: 이번에 재지 않아 그대로(220ms, 23.4mm/s)

명령 시간 변화
  1mm    172ms -> 458ms
  5mm    687ms -> 1068ms
  25mm  3353ms -> 4117ms

세 화면(작업 툴바 / 와이어 조정 팝업 / 팬던트)이 모두 이 파일을
쓰므로 한 번에 반영된다.

■ 함께 포함 (v1.1.207 미배포 시)
아크 중 용접 실측값 로그 추가.
  [WeldFeedback] current=...A voltage=...V trackVel=...mm/s
trackVel 부호가 한 방향으로 계속 나오면 아크 트래킹 상하 보정이
한계까지 밀고 있는 것이고, 0 근처를 오가면 수렴 중이다.

■ 확인 사항
1mm 버튼은 실측하지 않았다. 배포 후 1mm를 재서 크게 벗어나면
같은 방식으로 두 점 재실측할 것.
