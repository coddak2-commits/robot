- 용접 이동속도 계수(WELD_BATCH_SPEED_SCALE) 재산출: 수직 0.30 / 수평 0.175 -> 둘 다 0.431.
- 근거: DryRun 4회 실측으로 확정한 관계식 "실제 이동속도 = 5.795mm/s x 명령%" (오차 0.3% 이내). cm/min -> mm/s 정확 변환은 cpm/6 이므로 필요한 명령% = cpm/34.77, 코드 변환이 (cpm/15) x SCALE 이므로 SCALE = 15/34.77 = 0.431.
- 효과: 작업에 입력한 CPM이 실제 cm/min과 일치하게 됨. 기존에는 설정값의 41%(수평) / 70%(수직)만 실제로 나갔음.
- 계수 자체는 유지함. 2026-09-11 과속 사고는 이 계수가 빠져 speedRaw/15.0f가 그대로 나갔을 때 발생한 것으로, 제거는 여전히 금지.
- 주의: 이 변경과 함께 작업 데이터의 CPM 설정값도 실제값으로 바꿔야 함 (수평 50 -> 16.7, 수직 26 -> 27.5). 코드만 적용하고 CPM을 그대로 두면 수평이 약 3배 과속함.
