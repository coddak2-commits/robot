v1.1.232 - 터치 Z 여유값 추가 · 수평 시작 체류 제거

[1] 터치 결과에 Z 전용 여유값 (touch_offset_depth_z)

    터치센싱은 '와이어 끝이 모재에 닿았을 때 토치가 있던 자리'를 기록한다.
    dx/dy 에는 touch_offset_depth(기본 5mm)가 붙어 뒤로 물러서는데 dz 에는
    아무것도 안 붙는다. 그래서 용접할 때 토치가 접촉 높이에 그대로 서고,
    CTWD 가 터치 당시 와이어 길이와 같아진다.

      보이는 스틱아웃 = CTWD - 아크 길이 = (터치 때 와이어 길이) - 아크 길이

    와이어를 25mm 로 맞추고 터치하면 CTWD 가 25mm 로 고정되고, 아크가 8~10mm 를
    차지하므로 용접 중에는 15mm 정도만 보인다. 와이어 길이가 조금만 달라져도
    스틱아웃이 그대로 따라간다. 2026-10-08 현장에서 이 증상이 나왔다.

    이 값을 더하면 토치만 그만큼 높이 선다. 가로 위치(X/Y)는 안 건드린다.

      touch_offset_depth_z = 10  ->  CTWD 35mm  ->  스틱아웃 약 25mm

    기본값 0 이라 설치만 해서는 아무것도 안 바뀐다. 프런트에서 0~30mm 로
    제한하고, 범위를 벗어나면 touchSensing.zOffset.clamped 경고를 남긴다.
    적용되면 touchSensing.findDz.zOffset 로그가 찍힌다.
    Z 탐색을 실제로 한 포인트에만 붙인다. 안 한 포인트는 dz 가 0 이고 거기에
    더하면 없던 보정이 생긴다.

    설정 화면은 없다. welding_config 테이블에서 직접 바꾼다. 다른 touch_* 설정과
    같은 방식이다.

    주의: 모든 포인트에 똑같이 붙는다. 수평과 수직을 따로 주려면 값을 나눠야 한다.

[2] 파트 시작 체류 전부 제거 (사용자 요청)

    PART_START_DWELL_MS 를 전부 0 으로. P4/P5/P10/P11 의 1000ms 를 뺀다.
    이 체류는 모서리를 채우려고 넣었던 것이다(v1.1.158 수평, v1.1.202 수직).
    v1.1.228 에서 모서리를 별도 파트로 떼면서 그 역할이 모서리 파트로 넘어갔고,
    같은 자리에 체류까지 겹치면 2초를 머물며 쌓기만 한다.
    전부 0 이면 dwellAtPartStart 가 바로 반환하고, 아크를 켠 뒤 곧바로 배치
    이동으로 들어간다. 키는 남겨뒀다. 되살릴 때 값만 넣으면 된다.
    (v1.1.224 에서 수직 0, 여기서 수평·모서리 0)

[적용 절차]
  1. 각 기계에서 013 마이그레이션 실행
       database/migrations/013_touch_offset_depth_z.sql
     (사무실 PC / 노트북 / 펜던트 DB 가 전부 별개다)
  2. 설치
  3. 스틱아웃이 짧으면 touch_offset_depth_z 를 올린다. 10 부터 시작.

       UPDATE welding_config SET touch_offset_depth_z = 10 WHERE id = 1;

     바꾼 뒤에는 터치센싱을 다시 돌려야 반영된다. 저장된 보정값에 이미 들어가
     있는 값이라, 기존 작업을 그대로 불러 쓰면 옛 값이 적용된다.

[현장 확인]
  - 로그에 touchSensing.findDz.zOffset 이 찍히는지 (0 이면 안 찍힌다)
  - 모든 파트 시작점에서 멈추지 않고 바로 진행하는지
    (로그에 welding.partStart.dwell 이 안 찍혀야 한다)
  - 스틱아웃이 넣은 값만큼 길어지는지

[참고 - 스틱아웃 25mm]
  1.2mm 와이어 300A 면 보통 15~20mm 다. 길면 가스 보호가 약해지고 전류가
  떨어진다. 10 부터 넣어보고 비드 보면서 조정할 것.
