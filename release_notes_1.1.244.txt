v1.1.244 - 셀 화면 포인트 이름을 4파트 이름으로 표시

[배경]
셀 화면은 들어갈 때 마지막 작업을 자동으로 불러온다. 그 작업이 228~242 에
저장된 것이라 포인트 이름에 '모서리', '모서리 20mm' 문구가 남아 있었다.
243 에서 새 티칭 기본 이름은 4파트로 되돌렸지만, 이름도 작업에서 읽었기 때문에
저장된 작업을 불러오면 옛 이름이 그대로 보였다.

[수정]
    robot-front/src/pages/UcellSelect/hooks/useJobManagement.ts (loadJob)
      포인트 이름은 작업에 저장된 값 대신 UCELL_POINT_DEFINITIONS 의 이름을 쓴다.
      정의에 없는 id 일 때만 저장된 이름을 쓴다.
      좌표·조건 등 나머지 값은 종전대로 작업에서 읽는다.
      작업을 저장하면 DB 이름도 새 이름으로 바뀐다.

[DB]
    변경 없음.

[현장 확인 항목]
  - 셀 화면 포인트 목록에 '모서리' 문구가 없는지
    (P3 좌측 하단, P4 하단 좌측 시작, P5 하단 좌측 중간 등)
  - 설정 화면 '시스템 버전'이 1.1.244 인지
