v1.1.238 - 와이어 수동 조그 뜨거운 밀기 재보정

234 의 뜨거운 밀기 값으로 용접 직후 다시 재보니 요청보다 많이 나갔다.
송급에 엔코더가 없어 롤러 압력·라이너·스풀이 바뀌면 또 틀어진다. 234 와 같은
방식(5mm·25mm 두 점)으로 다시 맞춘다.

[실측 (2026-10-09, 뜨거운 상태)]
    234 값(지연 121ms, 10.93mm/s), 명령 시간 212 / 578 / 2408ms.

      요청      실측               평균
      1mm       2, 4, 6mm          4.0mm
      5mm       6, 7, 7, 8mm       7.0mm
      25mm      30, 27, 29, 30mm   29.0mm

    5·25mm 두 점 -> L(mm) = 12.02 x (t - 0.000s)
      속도 10.93 -> 12.02 mm/s,  지연 121 -> 0 ms (계산값 -4ms)
    검산: 25mm -> 2080ms -> 25.0 / 5mm -> 416ms -> 5.0

    1mm 는 2~6mm 로 흩어져 뺐다. 25mm 도 27~30mm 로 흩어지므로 보정 후에도
    매번 ±1.5mm 정도는 차이가 날 수 있다.

[수정]
    robot-front/src/lib/wireFeed.ts 의 WIRE_FEED_PROFILE_HOT.forward
      지연   121ms  ->  0ms
      속도   10.93  ->  12.02 mm/s

[안 고친 것]
    식은 쪽 밀기(117ms, 8.46mm/s)와 당기기(306ms, 23.42mm/s)는 그대로다.
    식은 상태 25mm 가 30mm 나온 측정이 한 번 있으나 한 점뿐이라 반영하지 않았다.
    뜨거운 판정 시간은 5분 그대로다(근거 없는 임의값. 시간별 실측 필요).
