터치센싱 접근 방향 수정 대상을 P7에서 P9/P10으로 정정 (두 포인트가 같은 위치(우측 수평 코너)에 티칭되어 있고, 해당 위치에서 U셀 간섭으로 충돌(code=185) 반복 확인됨). 로컬 +X에서 base -Y로 변경, 오프셋 크기는 기존과 동일. Home 복귀 후퇴 방향(P7 기준)은 기존 +X 유지. 파트 일부만 선택해 P9 또는 P10이 용접 시작점이 되는 경우의 시작점 접근 로직도 동일하게 -Y로 변경. 추가로 파트 전환(P6->P9) 직접 관절이동 시 곡선 경로로 인한 와이어 휨 문제 확인되어, 관절이동 전 base +X 방향으로 소폭 후퇴하는 완충 이동 추가 (실기 테스트 필요).
