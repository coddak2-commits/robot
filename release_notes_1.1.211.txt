v1.1.211 - 시작점 기어가기 거리/속도 재설정 (모서리 미충전 대응)

■ 문제
모서리에서 수직 비드와 수평 비드가 만나는 자리가 채워지지 않는다
(2026-09-30 사진). 파트 순서상 두 비드가 모두 모서리에서 아크를
켜고 떠나므로, 시작 직후의 얇은 구간 두 개가 모서리에 겹친다.

■ 기존 값이 동작하지 않던 이유
  3mm / 500ms = 6.0mm/s
  명령 1%    = 5.795mm/s
저속 이동이 아니라 용접 속도와 같았다. 프런트가 속도를
Math.round 로 정수화하고 1% 하한을 걸어둔 탓이다.
robot-core 의 clampMotionPercent 는 0.1%까지 받는다.

■ 수정
거리 3 -> 12mm. 속도를 체류시간 역산에서 용접 속도 대비 비율로 변경.

  const PART_START_CREEP_MM = 12;
  const PART_START_CREEP_SPEED_RATIO = 0.5;

  weldPct  = (moveSpeed / 15) * 0.431      <- 배치와 같은 환산
  speedPct = weldPct * 0.5                 <- 반올림하지 않음, 하한 0.1%

수평과 수직의 CPM 이 다르므로 고정 시간이 아니라 각 파트의 용접
속도에서 계산한다. 용접 조건을 바꿔도 비율이 유지된다.

로그에 계산 결과가 찍힌다.
  파트 시작 체류: P3 12mm 저속 이동
    (용접 0.86% x 0.5 = 0.43%, 2.49mm/s, 약 4.8초)

■ 적용 범위
수직 시작점(P1/P3/P7/P9)만. 수평(P4/P10)은 v1.1.210 대로 제자리
정지를 유지한다. 바뀐 변수를 하나로 두어 결과를 비교한다.

■ 조정
비드가 부족하면 거리 15mm 또는 비율 0.4.
과하면 비율 0.6~0.7.

■ 주의
배치 이동에는 설정의 속도 오버라이드(default_ovl)가 곱해지지만
기어가기가 타는 /motion/movel 경로에는 곱해지지 않는다.
오버라이드를 100 이외로 쓰면 그만큼 비율이 어긋난다.

파트당 아크 시간이 4초 안팎 늘어난다.
